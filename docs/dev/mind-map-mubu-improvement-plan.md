## 2. 固定边界与建议顺序

- 一份文件只包含一类图：思维导图与流程图保持独立，通过文档引用连接。资料库仍是创建、管理和改名的入口，不新增重复一级侧栏空间。
- 同一棵树驱动大纲和导图；共享保存、撤销、冲突与引用。视图切换不能复制文件、清空草稿或产生另一套存储。
- 继续使用 Kiln token、现有共享控件和 Noto Sans SC。借鉴幕布的操作组织与工作流，不复制品牌视觉，也不添加第二套设计系统。
- 文本输入、主题选择、树结构、视图状态分开处理。首先定义命令在哪个状态生效，再安排按钮与快捷键。
- 首批已实施 **P0 当前协议 + P1**；后续按用户要求实施大纲缩进、独立描述、子树聚焦及排版。未明确的幕布编辑边界继续单独待测；引用呈现、结构批处理/查找、显示设置/导出保留为后续范围。

| 阶段 | 输出 | 前置依赖 | 文件 schema |
| --- | --- | --- | --- |
| P0 | 两种视图与命令状态契约、真实参考证据表 | 无 | 不变 |
| P1 | 可发现的视图切换、安静工作区、帮助面板、视图状态保留 | P0 | 不变；状态先只保留本次打开会话 |
| P2 | 有明确光标/层级语义的大纲持续录入 | P0；P1 的模式提示 | 不变 |
| P3 | 主题描述和容易发现的文档引用 | P1；沿用已有 `note` / `links` | 不变 |
| P4 | 大纲主题多选、结构剪贴板、查找/聚焦 | P2 的状态边界；P3 的字段保留规则 | 剪贴板用独立内部版本；文件尽量不变 |
| P5 | 有限显示选项及可靠导出 | 前述编辑行为稳定；另定输出范围 | 仅阅读设置优先不写文件；新增布局字段需同步 Rust 契约 |

- [x] **P2.1 实施已定案的 Tab/Shift+Tab。** 直接复用 `indentMindMapNode` / `outdentMindMapNode`；不能增加节点数或重复生成主题。前一个同级不存在、根主题、折叠分支和深层节点必须稳定。
- [x] **P2.2 连续输入链路。** 测试 Enter 新主题、Tab 缩进、输入正文、Enter 新同级、Shift+Tab 提升、继续输入完整链路。保留普通点击光标、原文选区和多行自动高度。
- [ ] **P2.3 空主题与删除协议。** 依据 P0 明确 Backspace 是删除空主题、先提升还是合并；已有非空正文删除不触发结构变化。删除后按确定规则定位相邻主题，根主题不可删除。
- [x] **P2.4 方向键跨主题规则。** 编辑态先尊重原生文字光标，只有已定义边界才转到前后主题；结构选中态提供稳定主题导航，不把一次方向键当作新建或误删。
- [ ] **P2.5 撤销及组合输入。** 调整命令后检查受控 textarea 的历史、IME `isComposing` / keyCode 229 / Process 门禁，主题被撤销移除后焦点仍在大纲可继续输入。

若真实大文件测量显示整树扫描/渲染成为瓶颈，先记录节点规模、延迟与受影响操作，再决定索引/虚拟化/worker；不要因未来可能性能不足预先改写整个编辑器。

## 8. P5：有限显示设置、布局与导出

- [ ] **P5.1 显示设置最小集。** 优先大纲宽度（自适应/阅读宽度）、密度、描述首行/完整；沿用现有字族和 token。先作为本次工作区视图设置，不进入内容撤销。每个选项必须有真实可见效果，不只放菜单。
- [ ] **P5.2 导图布局单独规划。** 当前为单根自动树。左右分支、组织结构、逻辑图等若确有需要，先选一种布局并定义拖动归属；不可恢复为混合流程画布。新布局配置字段要同步 TS、Rust、验证器和兼容策略。
- [ ] **P5.3 先选择一种有用的导出。** 候选先层级 Markdown/纯文本大纲，或完整 SVG/PNG 图；由用户实际用途决定首个输出格式，不同时上 PDF、Office、XMind 等全部格式。
- [ ] **P5.4 定义导出范围与字体。** 整图/当前聚焦子树、折叠内容是否包含、描述及文档引用如何表示须明确。输出使用完整文字，不复用预览截断；图像边界不含编辑框、选中态和操作按钮；Noto Sans SC 加载/嵌入结果需验证。
- [ ] **P5.5 异步文件输出。** 大量解析、绘制编码和文件写入走异步流程，局部显示处理中/失败状态；取消不改变草稿。系统保存对话框和生成文件内容分开验收。

涉及：[布局](../../src/lib/mind-map-layout.ts)、[预览](../../src/components/shard/mind-map-preview.tsx)、[文字测量](../../src/lib/mind-map-text-metrics.ts)、[工作区](../../src/components/shard/mind-map-workspace.tsx)；仅在新增持久化字段或文件输出 command 时触及 [Rust](../../src-tauri/src/lib.rs)。导出可新建独立模块，不把逻辑塞进输入 handler。

成功标准：视图设置不改正文；输出层级、全文、描述与引用符合声明范围；特殊字符和超长行不损坏格式；原生保存可取消；导出错误不影响草稿；重新打开导出文件验证内容而非只断言返回成功。若涉及 schema，旧文件读取与新文件原生 round-trip 必须都有结果。

## 9. 实施及完成证据

每次只实施已选定的阶段/子范围，并在该阶段后记录「改动、验证、未测项」。已勾选项代表 P0/P1 与已验证的大纲缩进/持续录入。P3 的描述字段编辑、P4 的子树聚焦已由后续大纲改造交付；文档引用呈现、查找、多选剪贴板和导出等仍未完成。幕布可编辑样例与原生 IME 候选输入仍单独标注。不能用一次构建把未来阶段批量标记为完成。
