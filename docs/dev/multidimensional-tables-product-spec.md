# 多维表格产品与操作规范

> 历史方案（2026-09-15）：用户已确定从 Shard 产品中移除内置多维表格，详见 [只围绕碎片的设计](fragment-only-design.md) 与 [退役迁移计划](fragment-only-migration.md)。本文保留旧格式与交互证据，不再安排后续表格功能；实际代码退役与旧数据处理尚未实施。普通 Markdown 表格内容和飞书作为外部存储目标不属于被删除的表格产品。

日期：2026-09-08。依据用户明确要求：Shard 只提供一种可管理的表格产品——多维表格。本规范补充执行计划的产品交互约束，不扩大 M1 范围；实现状态见 [验收记录](multidimensional-tables-implementation.md)。

## 统一产品入口

- 资料库提供“新建多维表格”和“从 CSV / Excel 导入…”。一份 `.shardtable.json` 包含字段、记录和多个视图，沿用资料库目录；不再增加 Base 或工作空间层级。
- CSV / XLSX 是导入导出格式。已有 CSV 源文件可从操作菜单“导入为多维表格”直接进入预览；创建新的原生文件，保留源文件。XLSX 使用同一导入界面。
- 正文编辑器不再提供“插入表格”、Excel 转 Markdown 或另一套单元格编辑器。旧 Markdown 表格保留内容、源码编辑和阅读渲染；不自动删除、迁移或重写旧资料。
- 拖入 CSV / XLSX 时提示到资料库导入多维表格；旧 XLS 系列提示先另存 XLSX。其他文档导入继续使用原路径。

“多维表格”是产品名称，“表格视图”是其当前唯一视图布局。多个表格视图共享记录；筛选、排序、分组、字段显隐属于各自视图，删除视图不会删除记录。

## 当前操作契约

本轮以用户已打开的飞书桌面多维表格为直接参考，现场观察与适配边界见 [飞书参考记录](multidimensional-tables-feishu-reference.md)。界面依次为文档标题、独立视图标签、紧凑工具栏与网格；工具栏遵循 [Kiln 数据编辑器模式](../../vendor/kiln/references/components.md#data-editor-toolbar)。

所有表单控件消费共享 Kiln 组件，遵守 [强制共享控件规范](../../vendor/kiln/SKILL.md#shared-controls-are-mandatory)；字段选择、日期和勾选使用页面自绘控件，弹层交互不得触发网格提前提交。

| 操作 | Shard 行为 |
| --- | --- |
| 切换视图 | 标题下方常显视图标签及新增按钮，复制、重命名、删除放在视图菜单。窄窗口允许标签栏水平滚动；切换前校验正在编辑的单元格和设置草稿，中文组词、无效输入不能被切换丢弃。 |
| 配置字段 | 列头显示六种字段类型图标；点击名称编辑字段，箭头菜单提供升降序、筛选、分组、左右移动、隐藏、删除。操作按稳定字段 ID 定位；末列“新增字段”打开待应用草稿，字段配置使用带搜索、类型图标、显隐开关与主字段锁的锚定列表，编辑使用紧凑表单。未应用字段草稿遇到 Escape/外点保持打开，由确定/取消处理；明确保存与切换仍先校验并应用。主显示字段不能隐藏或删除，非空字段转类型仍受校验。 |
| 筛选、排序、分组 | 工具栏分别提供入口及启用数量，在入口下方弹出各自设置，不改变网格宽度，按当前视图保存。分组标题内嵌于表格，显示记录数，支持鼠标/键盘单组折叠和全部展开/折叠；折叠状态只保留在当前会话，并按视图和分组字段隔离。 |
| 查看记录 | 行号/单元格右键提供查看详情与删除，工具栏保留详情按钮。宽屏详情覆盖右侧，底层网格不缩宽；窄屏只显示详情。类型图标及字段名在左、值区在右。表尾和工具栏均可添加记录。 |
| 多行统一修改 | 行首勾选记录后出现批量操作栏，选择一个字段统一设置或清空；打开面板时冻结稳定记录 ID，只改该字段，一次撤销。选字段本身不产生写入，未填写、false 与空多选保持不同语义。 |
| 编辑与批量粘贴 | 按类型编辑；Enter/Tab 提交和移动、Esc 取消；中文候选期间不抢按键。矩形选择、TSV 复制粘贴和撤销沿用已有契约，转换失败保留原值与草稿。 |
| 保存 | 合法编辑进入保存队列，展示保存中/已保存/失败。导航、结构操作与退出等待真实结果；失败保留草稿。此为 Shard 自身文件一致性方案。 |
| 导入导出 | 同一界面选择工作表、预览、字段类型及映射；校验成功再创建。导出区分全部数据与当前视图。CSV/XLSX 不承诺工作簿格式或公式保真。 |

以上常用交互已接入。分组统计当前为记录数量；折叠不删除记录，不改变导出范围，也不占用撤销历史。复制、清空和粘贴跳过分组标题与折叠记录；标题本身不可编辑或作为粘贴起点。行列映射变化时清除旧选区，带旧显示版本的命令被拒绝。保留手动保存入口与自动保存机制。

## 后续范围与验收边界

M2 再实施看板、日历、记录正文/笔记引用、跨表关联与汇总、搜索引用；M3 再实施公式。多人协作、权限、自动化和 AI 功能不随本次要求追加。

自动化需验证入口唯一性、旧正文兼容、源文件直接预览、视图切换草稿保护、字段 ID 定位、工具栏状态和窄窗几何，以及批量原子性、分组剪贴板、折叠状态隔离和旧选区保护。浏览器与 WebKit 测试不能替代真实 Tauri 的中文候选输入、原生横向滚动和端到端性能；完整 M1 门禁继续以 [覆盖矩阵](multidimensional-tables-acceptance-matrix.md) 为准。
