# 图文档分离实施计划

2026-09-07。用户确定：每份文件仅存放思维导图或流程图，通过文档引用建立跨图关系。本计划替代旧图形工作台任务清单中的混排目标。范围为本地实现与分层验证，保留已有工作区改动及真实资料库，不提交、不部署。

## 文件与交互规则

- 思维导图沿用 `.shardmap.json` / `shard.map`，独立树编辑器负责布局、主题选择、键盘操作与属性、大纲面板。
- 流程图采用 `.shardflow.json` / `shard.flow`，支持流程、判断、起止、文字和文档引用；禁止嵌入可编辑导图副本。
- 两类图继续在资料库中创建、管理、改名和移动。文档引用保存稳定 ID，笔记中使用 `shard://map/ID` 或 `shard://flow/ID`；跳转之前保存当前文档，失败保留草稿和当前页面。
- 旧 `.shardcanvas.json` 只读打开；显式拆分生成每棵独立导图、一份流程图（如有流程对象）和关联说明 Markdown。保留原文件及原有跨图连线信息，不覆盖、不自动迁移真实数据。
