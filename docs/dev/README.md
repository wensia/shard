## 历史材料

本目录既有的 `information-architecture-*`、`multidimensional-tables-*`、`mind-map-*`、画布与资料库工作台计划保留为历史记录。其中继续发展资料库、导图、流程图、画布、多维表格和独立密匣产品的路线已被新方向取代；旧状态如“待实施”“下一阶段”仅属于当时计划，不作为新的执行队列。

`docs/design/` 下早期个人资料工作台、碎片与资料库分离的方案具有相同历史定位。代码事实、当时验收结果和可复用的碎片/编辑器约束仍可参考；与当前目标冲突的产品决定以新方案和用户最新指令为准。

项目执行约束继续以当前 AGENTS.md 为准，通用 UI 规范继续以 [Kiln](../../vendor/kiln/SKILL.md) 为准。不要因产品文档更新就自动调整运行进程、数据库、Git remote、连接授权或用户数据目录。
