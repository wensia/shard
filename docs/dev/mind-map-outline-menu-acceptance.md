# 大纲主题菜单验收

日期：2026-09-08。依据用户提供的幕布菜单截图，本轮完善“···”的行为与视觉层次。本记录替代下级主题验收中“结束输入后显示整行底色”的旧规则。

## 当前行为

- 只有主题菜单打开期间显示该主题整行浅色底；正文、描述、结束输入、键盘导航、折叠及聚焦均不显示整行底色。拖入子主题使用虚线轮廓提示。
- 一次只打开一个主题菜单；可单击另一行“···”切换。弹层优先放在触发按钮左侧，空间不足自动翻转，避开同级按钮列。
- Esc 或再次点击触发按钮关闭时，恢复该主题原来的正文/描述光标和选区。点击其他输入框或控件时不抢回焦点。
- 菜单分为主题操作、结构操作和删除区：编辑主题、编辑描述、折叠/展开、聚焦、添加子节点/同级节点；移动主题子菜单提供上移、下移、缩进和反缩进。根据根节点、首尾位置和层级禁用无效动作。
- 聚焦主题在菜单关闭完成后交接到大纲容器，后续 Enter 创建当前范围的子主题，与圆点聚焦一致。编辑和结构动作将焦点交给目标输入框。
- 菜单及移动子菜单归属于各自工作区，保存、撤销和重做快捷键继续生效。撤销移除菜单所属节点后清除菜单状态，重做不会重新弹出旧菜单。
- 底部显示真实更新时间和当前主题正文的非空白字数。未新增文件字段、富文本格式或没有实现的占位菜单项。

## 视觉规格

继续使用 Kiln：14px 常规字重菜单项、32px 行高、16px 图标、12px 快捷键及元信息、6px 圆角、细边框和浮层阴影。当前主题底色为低浓度主色；普通悬停及菜单项焦点使用中性色。

原有 6px 圆点、28px 层级缩进和父级竖线中轴保持不变。菜单外缘上下各保留 4px 无残线留白，多行正文和描述不移动首行锚点。

## 验证

- 8 项定向用例通过，WebKit / Chromium 各 4 项：菜单独立命中与保存撤销、单实例开合与光标恢复、元数据及移动边界、圆点竖线绘制。覆盖 1280px / 640px 主菜单及子菜单布局。
- 最后收紧快捷键间距后再次通过 2 项几何用例。1280px 下两引擎弹层均位于触发器左侧，宽度分别约 189px / 186px，正文完整可见；640px 自动翻右且不越界。
- 精确几何在菜单入场动画完成后读取；圆点/竖线中轴偏差为 0px，菜单上下 4px 留白无残线，远端线段显示前后亮度差不超过 1。
- `pnpm build` 和 `git diff --check` 通过。构建保留既有的大包体积提示。
