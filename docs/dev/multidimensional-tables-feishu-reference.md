# 多维表格：飞书桌面现场参考与 Shard 适配

日期：2026-09-08。用户已在本机飞书打开多维表格，要求直接仿照其设计。此文记录该界面的现场观察与 Shard 的适配约束，补充 [产品与操作规范](multidimensional-tables-product-spec.md) 和 [执行计划](multidimensional-tables-plan.md)。实现、测试和原生验收状态以 [验收记录](multidimensional-tables-implementation.md) 为准；参考观察本身不代表 Shard 已完成实现。

## 观察范围

参考对象为用户已打开的 macOS 飞书空白多维表格。通过界面查看、打开菜单和弹层进行只读观察，没有新增记录或字段，也没有点击确定保存。以下内容只记录产品结构与操作模式，不保存私有文档地址、文档标识、账号或其他标签页内容。

| 现场已观察 | 设计含义 |
| --- | --- |
| 顶部文档身份区，下方独立视图标签栏 | 文档、视图、当前视图操作分层，用户先确认正在编辑的对象 |
| 当前表格视图标签含类型图标和更多操作，相邻提供新增视图入口 | 切换视图常显，视图管理就近，不与字段设置混在同一面板 |
| 视图更多菜单含重命名、复制视图、保护视图和删除视图；仅有一个视图时删除禁用 | 常用管理与当前视图绑定，最后一个视图有保护边界 |
| 视图栏下为紧凑图标与文字工具栏；添加记录在最左，字段配置、视图配置、筛选、分组、排序在中间，撤销与重做等弱操作在右 | 按工作顺序组织命令，表格保持主要视觉面积 |
| 字段配置打开包含搜索、字段列表、底部新增字段的小弹层 | 集中查找与管理字段的入口轻量，保留网格上下文 |
| 编辑字段使用就近独立弹层，包含字段名称、字段类型、默认值及取消/确定 | 单字段编辑与字段目录分开，临时修改有明确提交边界 |
| 字段类型选择包含搜索、分组列表与类型图标 | 用可识别的类型选择器替代普通原生下拉菜单 |
| 筛选、分组、排序各自打开工具栏锚定弹层，网格位置保持不变 | 配置是局部临时交互，避免表格因侧栏出现而反复变窄 |
| 列头有主字段锁定标识或类型图标，末列与末行均提供加号入口 | 字段身份可扫描，增加字段或记录的入口与编辑位置相邻 |
| 列头右键菜单含修改字段、描述、填色、复制、提醒、创建编组、向右插入、冻结、升降序、按该字段分组或筛选 | 字段结构与视图快捷操作靠近列头，不必先进入全局设置 |
| 行号右键菜单含上下插入、提醒、分享、复制链接、总结、查看详情、子记录、历史、评论和删除 | 记录操作按所在行提供上下文入口；出现的菜单项不代表 Shard 的支持范围 |
| 从已有空白行打开“查看详情”后，右侧抽屉覆盖表格右半部，左侧表格仍可见；顶部为上下记录和关闭，下面为记录标题、详情/历史标签及字段列表 | 记录详情保留上下文；字段行用左侧类型图标和名称、右侧值区对齐 |

这些观察来自空白多维表格及其中已有空白行，打开详情时没有编辑记录。包含内容的分组折叠与统计、多行批量修改、剪贴板、撤销和数据持久化没有由本次观察验证；菜单内权限、提醒、分享、AI 总结、历史及评论等能力也没有执行验证。不把 Shard 已有行为或其他资料结论写成飞书现场实测。

## Shard 的直接适配

Shard 采用上述交互结构，沿用 [Kiln 数据编辑器工具栏模式](../../vendor/kiln/references/components.md#data-editor-toolbar)。字体保留项目现有的 Noto Sans SC 与回退策略；颜色、间距、控件密度、圆角、阴影和焦点使用 Kiln token，不引入飞书品牌色或另一套组件系统。

| 区域 | Shard 适配约束 |
| --- | --- |
| 文档与视图 | 保留资料库内单个 `.shardtable.json` 的标题及保存状态，下面依次为视图标签、工具栏、网格。视图类型图标、当前视图菜单与新增视图入口就近排列 |
| 工具栏 | 添加记录放左侧；字段配置、视图配置、筛选、分组、排序形成连续工具组；撤销、重做等辅助动作弱化。使用共享 Button 和有文字标签的图标，常态可透明，hover、展开、启用、键盘焦点明确；不修改公共 Button 的默认语义 |
| 字段管理 | 搜索与字段列表放入锚定弹层，新增字段入口在列表底部；单字段编辑使用独立、就近的草稿表单。名称、类型及当前支持的属性可编辑，取消不写入；Escape/外点遇到未应用字段草稿保持打开，明确确定或保存/切换时校验后提交 |
| 字段类型 | 只提供 Shard 当前支持的文本、数字、日期、单选、多选、勾选。字段目录及列头显示类型图标，当前类型编辑使用六项共享 Select；没有移植飞书的大类搜索选择器。不因参考界面存在其他类型而展示不可用功能 |
| 视图配置 | 筛选、排序、分组各自从对应工具栏入口打开锚定弹层，配置当前视图；弹层不占据新的常驻侧栏，不改变网格宽度 |
| 网格入口 | 保留稳定字段 ID 的列头编辑与菜单、主字段保护、末列新增字段；末行入口用于新增记录。空表也应保留可发现的字段和记录入口 |
| 记录详情 | 保留右侧详情与左侧表格上下文，参考类型图标、字段名与字段值的排列。飞书的历史标签和其他协作入口不作为 Shard 已有功能展示 |
| 现有能力 | 保留分组折叠与记录数量、多行统一修改、记录详情、撤销、类型校验和导入导出等已经实现的行为。它们需要 Shard 自身回归测试，飞书现场观察不构成 Shard 行为验收证据 |

飞书字段表单中的默认值、视图保护以及列头与行号菜单中的扩展操作是已观察入口，不等于 Shard 本轮已支持。当前数据契约没有的属性和能力不显示虚假可用项，也不为追求外观一致而绕过类型转换限制。菜单优先保留当前能够完整执行的动作。

## 必须保留的产品与数据边界

- 一种可管理表格产品：多维表格。CSV/XLSX 继续作为交换格式，资料库仍是组织层级；不新增飞书式导航壳层、Base 工作空间或多张表导航。
- 多视图共享同一组字段与记录，视图配置独立。保持稳定 ID、Worker 查询与校验、异步保存队列、结构操作保护和现有 Git 提交策略。
- 所有可见控件与弹出内容均使用共享 Kiln 组件。原生 `select`、日期弹窗、复选框等禁用规则保持有效，不能用外观 CSS 包装默认控件。
- 在网格与弹层、弹层与类型选择器之间移动时，保留有效草稿；无效输入、中文候选、保存失败不能被关闭、切换视图或焦点变化丢弃。
- 不随外观参考增加仪表盘、AI、多人权限、自动化、公式或未规划字段类型；看板、日历、记录正文及跨表关联继续遵循原有阶段计划。

## 适配验收

- 验证文档身份、视图标签、工具栏和网格的排列，以及空表和有记录表的新增入口。
- 在宽窗和窄窗打开字段列表、单字段表单、字段类型选择、筛选、分组与排序，核对锚点、滚动范围、遮挡和网格几何；记录真实计算样式。
- 用鼠标和键盘验证弹层打开、选择、取消、应用与焦点返回；验证嵌套类型选择器不触发网格提前提交。
- 对草稿保护、字段 ID 定位、主字段限制、分组投影、批量原子修改、剪贴板和撤销运行相关回归，避免结构调整改变已有数据行为。
- 浏览器及 WebKit 验证与真实 Tauri 验收分别记录。本轮现场参考不是 Shard 原生中文输入、横向滚动、IPC、重启恢复或端到端性能的完成证据。
