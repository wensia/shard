# 幕布式大纲实施清单

日期：2026-09-08。依据用户最新要求「大纲的设计与操作直接照抄幕布」，替代上一批暂时保留大纲 Tab/Shift+Enter 的取舍。本轮范围为大纲，不改变导图的 XMind 式创建键位，也不合并流程图文件。

- [x] 复核幕布实际大纲页面与官方键位，区分已验证和未知边界。
- [x] 独立文档标题、正文阅读宽度、16px 正文与 32px 行节奏、28px 层级缩进。
- [x] 取消常驻把手、菜单、文字框描边和整行底色；圆点兼顾拖动/聚焦，小三角独立折叠。
- [x] Tab 缩进当前主题，Shift+Tab 提升，结构操作保留文字插入点；标题 Enter 进入第一主题。
- [x] Shift+Enter 进入/退出主题描述，描述 Enter 原生换行；旧多行标题原样保留，并提供 Alt+Enter 换行。
- [x] 圆点和 Mod+] 聚焦子树，面包屑和 Mod+[ 返回；仅改变视图，不改根节点、文件或撤销历史。
- [x] Mod+Shift+↑↓ 重排，Mod/Alt+. 折叠；普通空标题退格保留已有子树、描述和引用。
- [x] 完成新增双引擎交互/几何、大纲既有行为与 P1 连续性回归：累计 71 项 UI、16 项树模型单测。
- [x] 完成构建、差异校对与隔离原生输入/保存/重开验收；原生候选词输入法仍单独待测。

结果及验证层级见 [本轮验收记录](mind-map-mubu-outline-acceptance.md)。
