# 思维导图交互契约

当前协议已按用户要求区分两种视图：大纲采用幕布式文档排版、缩进、描述和子树聚焦；导图保留原有创建主题键位。思维导图和流程图继续使用独立文档。更新与验收见 [幕布式大纲清单](mind-map-mubu-outline-tasks.md)。

## 状态与命令范围

| 状态 | 焦点与选择 | 命令范围 |
| --- | --- | --- |
| 导图选中 | 主画布容器持有焦点，主题有选中样式，没有输入光标 | 创建、删除、层级、主题导航 |
| 导图文字编辑 | 当前主题的 textarea 持有焦点 | 文字输入与连续建树 |
| 大纲文字编辑 | 当前行 textarea 持有焦点 | 文字输入与连续建树；点击行内文字只定位光标，不重新全选 |
| 大纲描述编辑 | 当前主题的独立描述 textarea 持有焦点 | Enter 换行，Shift+Enter / Esc 返回标题原插入点；Tab 正常切换焦点 |
| 大纲结束输入 | 大纲容器持有焦点，主题选择保留 | 新建、继续编辑、上下导航、删除 |
| 大纲主题菜单 | 仅菜单所属主题显示整行底色；主菜单和移动子菜单持有焦点 | 菜单命令与工作区保存、撤销、重做 |
| 工具栏、属性、帮助 | 相应控件持有焦点 | 控件自身键盘行为；Tab / Shift+Tab 正常切换控件，不改变主题树 |
| 输入法组合 | `isComposing`、`Process` 或 `keyCode === 229` | 交给输入法确认候选词，不创建、删除或移动主题 |

`Mod` 在 macOS 显示 `⌘`，其他平台显示 `Ctrl`；`Alt` 在 macOS 显示 `⌥`。当前 handler 同时接受 `metaKey` 和 `ctrlKey`。按键帮助只展示当前视图及通用命令，由工具栏可见按钮打开，不占用已有的 `Mod+/` 折叠命令。

## 导图选中状态

| 输入 | 行为 |
| --- | --- |
| Enter | 在后面新建同级并编辑；根主题新建子主题 |
| Shift+Enter | 在前面新建同级并编辑；根主题新建子主题 |
| Mod+Enter | 插入父主题并编辑；根主题不处理 |
| Tab | 新建子主题并编辑，展开被折叠的目标 |
| Shift+Tab | 提升一级；根主题及根的直接子主题不改变 |
| F2 / Space / 双击 | 编辑主题文字；仅单选可编辑 |
| 直接输入可打印字符 | 用首字符替换原文并继续输入；不把组合键当文字 |
| Backspace / Delete | 删除选中主题及其子树，排除根主题 |
| Mod+Backspace / Mod+Delete | 仅删除选中主题，子主题提升一级 |
| ← / → | 父主题 / 第一个子主题；向右先展开折叠节点 |
| ↑ / ↓ | 上一个 / 下一个同级主题 |
| Alt+↑ / Alt+↓ | 在同级中上移 / 下移 |
| Mod+/ | 展开 / 折叠非根主题的子树 |
| Mod+0 | 适合画布；无选择时也可用 |
| Esc | 清除主题选择 |

结构命令不能冒泡为工作区关闭操作，特别是选中态 Mod+Enter 插入父主题后不得关闭工作区。多选删除与拖动只处理顶层被选主题，避免重复处理同时选中的父子节点。

## 文字输入状态

| 输入 | 导图 textarea | 大纲 textarea |
| --- | --- | --- |
| Enter | 新建同级并编辑；根主题新建子主题 | 普通主题新建同级并保留原文；文档/聚焦标题进入第一主题，无子主题时创建 |
| Shift+Enter | 原生文字换行 | 进入独立主题描述；描述内再次按下返回标题 |
| Alt+Enter | 无专门约定 | 主题文字内换行，保留旧多行正文的输入能力 |
| Mod+Enter / Esc | 结束输入，保留文字和选择，焦点返回编辑器容器 | 相同 |
| Tab | 新建子主题并编辑 | 将当前主题缩进到前一个同级下面，保留文字选区；根主题/首个同级不新增 |
| Shift+Tab | 提升一级 | 相同 |
| 空文字 Backspace | 删除当前非根主题及其子树 | 仅移除没有描述、引用和子主题的空叶；有内容时尝试提升并保留全部内容 |
| 空文字 Delete | 删除当前非根主题及其子树 | 原生文字删除，不删除主题 |
| ↑ / ↓ | 原生光标移动 | 光标在全文开头 / 末尾且无选区时进入相邻可见主题，否则原生光标移动 |
| Alt+↑ / Alt+↓ | 没有主题重排命令 | 在同级中上移 / 下移；主键为 Mod+Shift+↑ / ↓ |
| Mod+A / C / V | 原生文字全选、复制、粘贴 | 相同 |

长文字、连续空行和尾部空行必须保留。输入框自适应高度，光标可见，不因重新选择主题而选中全部文字。普通文字剪贴板不等于主题剪贴板，本轮不展示尚未实现的主题复制、剪切、粘贴或批量结构编辑。

大纲结束输入后，Enter 创建同级（当前为聚焦标题时创建子主题），Tab / Shift+Tab 缩进 / 提升；F2 / Space 回到当前主题输入；↑ / ↓ 进入相邻可见主题；Backspace / Delete 删除当前非根主题及子树。Shift+Enter 编辑描述。Mod+Shift+Backspace 明确删除主题及子树；Mod/Alt+. 折叠当前；Mod+] 聚焦当前、Mod+[ 返回上一级。描述输入中的 Enter 不执行主题结构命令。

## 指针与视图

导图单击只选择；Mod+单击切换多选，Shift+单击按可见主题序列连续选择，空白处拖动框选。根主题单独选择，不参与拖动。主题拖动根据落点提示调整层级与顺序，不允许进入自己的后代；多选一起移动。

滚轮和双指滑动平移导图，Mod+滚轮或触控板捏合缩放。先单击空白取消选择后，Space+拖动可使用抓手。已有主题选中且画布持有焦点时，Space 是进入文字编辑，因此帮助不能写成“任意状态按 Space 平移”。

大纲单击文字直接输入，单击圆点聚焦子树、拖动圆点调整层级与顺序，小三角独立控制折叠。聚焦后标题变为当前主题，面包屑返回祖先或完整大纲；整个过程不改文件 rootId、父子关系或内容历史。大纲本轮没有主题多选协议。

下级主题使用灰色圆点、固定层级缩进及对齐祖先圆点的竖线；折叠主题显示圆点外圈。主题菜单位于圆点左侧，与展开按钮独立命中；只有“···”菜单打开期间显示当前主题行底色。普通点击、文字输入、结束输入、键盘导航、折叠和聚焦均不高亮整行，拖入子主题使用虚线轮廓提示。多行文字和描述共用对应子树的引导线，后续无关同级不延续该线。圆点与竖线几何见 [下级主题设计验收](mind-map-outline-children-acceptance.md)，菜单最新行为见 [主题菜单验收](mind-map-outline-menu-acceptance.md)。

主题菜单保持单一打开实例，弹层优先位于触发按钮左侧，空间不足时翻转；同级按钮列不被弹层覆盖，可单击切换主题菜单。Esc 或再次点击触发按钮关闭后恢复该主题原来的文字/描述插入点及选区；点击其他文字或控件时，焦点留给点击目标。菜单命令结束后焦点交给命令结果，聚焦主题保持在大纲容器。主题删除或退出当前可见范围后清除菜单状态，撤销/重做不会重新弹出旧菜单。

视图切换只切换同一主题树的编辑投影，选中主题保留；各视图位置由工作区保留。工具栏、属性和快捷键面板不能偷走编辑器的结构键，也不能让工作区全域拦截 Tab。

面板默认收起，属性和帮助互斥；面板或工具栏内 Esc 关闭面板并返回原编辑器焦点。焦点已回到编辑区时，Esc 先执行结束输入或取消选择，保持旁边的面板打开。组合输入期间禁用视图与面板切换。

## 工作区通用行为

Mod+S 保存，Mod+Z 撤销，Mod+Shift+Z 重做。结构操作进入独立历史步；文字使用现有合并键进入历史。保存、撤销和重做仅在当前工作区及归属该工作区的主题菜单（包括移动子菜单）内生效，组合输入期间不执行。

源码对应：

- `src/components/shard/mind-map-canvas-editor.tsx`：`handleCanvasKeyDown`、`handleNodeKeyDown`、`selectNodeFromModifierState`、`handleWheel`。
- `src/components/shard/mind-map-outline-editor.tsx`：`handleKeyDown`、`handleOutlineKeyDown`、`changeStructure`。
- `src/components/shard/mind-map-workspace.tsx`：工作区 `handleShortcut` 与焦点路由。
- `src/lib/mind-map-tree.ts`：`addMindMapSibling` 根主题处理、层级与删除边界。

验收应分别覆盖导图选中、导图输入、大纲输入、输入法组合、工具栏焦点和面板关闭回焦，不以按钮点击成功替代键盘链路验证。

幕布官方帮助未明确中段 Enter 拆分与全部空主题退格边界，未经可编辑样例实测不宣称完全等同。当前普通 Enter 保留原文，描述、引用及子树不因标题为空而被普通退格丢弃。
