# 幕布公开产品资料核对

核对日期：2026-09-08。来源仅为幕布官方帮助中心与官网；本文记录公开说明，不代表已在登录后的编辑器逐项操作验收。用户提供的真实文档界面观察应单独记录。产品行为与帮助文章矛盾时，以当前界面验证为准，保留差异。

## 产品模型

幕布以层级大纲组织内容，同一份内容可切换为思维导图。圆点是信息单元，缩进是包含关系；移动、缩进、折叠用于整理结构。由此可借鉴的是「一份结构，两种视图」，并不要求把独立流程图混入思维导图。[官方定位](https://mubu.com/help)

## 编辑与键盘

以下为官方明确列出的协议。快捷键表使用 Windows 表记；官方给出的 macOS 对应为 Ctrl → ⌘、Alt → ⌥、Shift → ⇧。自定义快捷键意味着用户账号配置可能不同，真实页面须核对默认与当前值。[快捷键说明](https://mubu.com/help/14)

| 场景 | 公开说明已证实 | 对 Shard 的启示 |
| --- | --- | --- |
| 大纲建立层级 | Enter 新建主题；Tab 将当前主题缩进；Shift+Tab 提升当前主题；可拖动重排 | 大纲的 Tab 不应无条件复制导图的「新建子级」语义。先定义现有内容如何变更父级。[大纲编辑](https://mubu.com/help/10) |
| 导图建立结构 | Enter 新主题；Tab 新建下级；Shift+Tab 插入上级 | 同一按键可根据视图改变结构操作；插入上级的具体挂接及根节点边界仍需实测。[导图编辑](https://mubu.com/help/28) |
| 主题与描述 | Shift+Enter 在主题与独立描述区间切换 | 幕布此键不是主题内换行；不能直接覆盖 Shard 已建立的换行协议。[描述](https://mubu.com/help/20) |
| 多选 | 鼠标拖动多选；Ctrl+A 支持由当前节点扩大到全文 | 文字选区、单节点选择、结构多选需要明确分层；Ctrl+A 的精确阶段与焦点边界待实测。[多选](https://mubu.com/help/17) |
| 操作可发现性 | 圆点悬停可呼出整主题菜单；快速菜单模式使用圆点左侧按钮 | 正文应保留可编辑空间，结构操作通过稳定而紧凑的触发点出现。[菜单模式](https://mubu.com/help/31) |
| 局部格式 | 选中文本后显示悬浮格式工具栏；整主题也可应用格式 | 不把「文字格式」和「结构命令」塞进同一个常驻大面板。[文字样式](https://mubu.com/help/25) |

值得纳入 Shard 命令清单的公开快捷键：撤销/重做、Shift+方向键多选、Ctrl+Shift+方向键上移/下移、Ctrl+D 副本、Ctrl+[ / ] 返回父主题/进入当前主题、Ctrl+Alt+L 复制主题引用、Ctrl+F 文内搜索、Ctrl+Shift+F 全局搜索、Esc 关闭当前面板、Ctrl+/ 快捷键面板。折叠具有当前主题、同级、指定深度和全部四种范围。[快捷键说明](https://mubu.com/help/14)

以上是功能与键位参考，不是要求全部原样接管。光标中间 Enter 的拆分行为、空主题退级、Backspace 合并、IME 组合态、跨节点粘贴、撤销粒度和拖拽命中区均未由本文公共资料确认，需要单独观察与测试。

## 阅读、聚焦与信息密度

| 能力 | 官方已证实 | 可迁移原则 |
| --- | --- | --- |
| 主题详情 | 单击圆点进入主题详情；顶部导航支持返回文档与切换同级 | 聚焦是局部结构浏览，有明确退出路径，不等同于简单隐藏侧栏。[专注模式](https://mubu.com/help/29) |
| 描述密度 | 可只显示描述第一行；点开查看全文；也可设置全部显示 | 短标题承载结构，长说明独立展开，避免每个节点因正文变成巨卡片。[描述](https://mubu.com/help/20) |
| 导图折叠 | 收起分支后显示下级主题数量，点击数字展开 | 隐藏内容必须可感知，折叠入口与节点编辑命中区应分开。[导图编辑](https://mubu.com/help/28) |
| 阅读模式 | 电脑/网页大纲提供预览入口；文章说明导图阅读模式有端差异 | 编辑、选择与阅读状态应明确；当前网页导图是否另有只读入口需实测。[阅读模式](https://mubu.com/help/62) |
| 演示 | 全屏浏览，支持缩放、夜间模式、进入子主题；文章说明不能编辑及展开收起 | 演示可做独立模式，避免编辑工具干扰内容。[演示模式](https://mubu.com/help/37) |

## 导图结构、样式与附加信息

| 能力 | 官方已证实 | 边界 |
| --- | --- | --- |
| 框架与配色 | 右侧入口调整配色及框架；选中主题可编辑文字格式、描述、图片 | 公开正文没有给出当前所有结构名称、主题数量与侧栏尺寸，需真实页面截图核对。[导图编辑](https://mubu.com/help/28) |
| 概要 | 选同级主题生成概要，可拖动范围边界；概要不进入大纲、不能再生子分支 | 属于导图表现层元数据，不能在切回大纲时误当正文节点。[概要](https://mubu.com/help/122) |
| 关联线 | 在两个导图主题间建立关系，编辑关系文字并调整端点/角度；颜色跟随配色 | 它表达图内非树关系；跨文档引用应另建文档链接。官方暂不支持自定义线形。[连接线](https://mubu.com/help/118) |
| 图片 | 主题可插图；大纲可拖动调整上下/横排顺序；选择后拖动改变尺寸 | 官方说明导图多图会用缩略图展示，顺序调整在大纲完成。[图片](https://mubu.com/help/27)、[排列及缩略图](https://mubu.com/help/121) |
| 待办 | 主题可转为待办、设置到期与提醒；支持多选批量操作和 Markdown 输入 | 网页/电脑提醒通知存在端限制，不应推断全部跨端能力。[待办](https://mubu.com/help/64) |
| 编号 | 自动延续编号，也支持给已有主题批量编号；不同层级多选时只作用于最高层级 | 编号应是结构展示功能，避免后续重排产生手写序号失配。[主题编号](https://mubu.com/help/133) |
| 表格与学习内容 | 有基础表格、公式、文字挖空 | 这些是后续内容扩展，不是大纲输入与图形布局可靠之前的优先项。[表格](https://mubu.com/help/52)、[挖空](https://mubu.com/help/53)、[官方目录](https://mubu.com/help) |

## 文档连接、搜索与定位

| 能力 | 官方已证实 | 对 Shard 的启示 |
| --- | --- | --- |
| 文档链接 | 输入 @ 后按文档名引用，点击可跳转 | 节点中连接其他文档，保持各图文件的类型独立。[双向链接](https://mubu.com/help/33) |
| 反向引用 | 文档底部展示引用自己的文档，可反向跳转 | 文档链接要能被反查，而不是只能单向打开。[双向链接](https://mubu.com/help/33) |
| 关联发现 | 按标题关键词寻找可能相关文档；用户可决定建立引用；另有文档关系图 | 自动发现与已确认的关系应有区别，不能自动将搜索命中写成关系。[双向链接](https://mubu.com/help/33) |
| 文字超链接 | 为选中文本设置 URL，可修改或删除 | 文本选区与整节点文档引用需要分别定义。[超链接](https://mubu.com/help/21) |
| 文内查找替换 | 文档搜索入口/快捷键打开搜索，展开替换区后操作 | 搜索结果应定位到节点，并处理其折叠祖先；后半项是 Shard 设计建议，非已实测幕布行为。[查找替换](https://mubu.com/help/8) |
| 标签和人名标记 | # 标签可点击筛选同标签主题；@ 人名也可作为可搜索标记 | 主题可成为搜索定位粒度；不要将 @ 文档、@ 人名当成同一数据对象。[标签](https://mubu.com/help/32)、[@ 功能](https://mubu.com/help/34) |

主题引用链接的存储格式、重命名后稳定性、被引用主题删除状态、搜索命中是否展开祖先及高亮规则，公开说明未确认。

## 导入、导出与互通

电脑和网页官方列明：导入 XMind、FreeMind、OPML、Markdown；大纲导出 Word、PDF、Markdown、图片、HTML、OPML；思维导图导出 PDF、图片、FreeMind。导图格式导出须在导图视图操作；当前说明不支持批量导出，FreeMind 导出会遗漏图片和描述。[格式与限制](https://mubu.com/help/30)

官方还说明 Markdown 文本粘贴可生成文档结构，但剪贴板来源和格式影响识别。[Markdown 粘贴](https://mubu.com/help/57)

Shard 应优先验证导入/导出对父子顺序、空节点、多行正文、描述和引用的保真；有损格式先明确损失，不能把成功生成文件等同于完整往返。此段为工程建议，未验证幕布的转换实现。

## 新能力与资料冲突

- 官方新增「文档透视图」：从现有文字提取流程、顺序、交互、状态等关系，先选择视角再生成图；公开说明限超级会员的网页/电脑端。它不是大纲换皮。对 Shard 可作为未来从文档派生独立图文件的参考，不改变目前思维导图与流程图分开保存的决定。[文档透视图](https://mubu.com/help/132)
- 旧基础页说不支持概要，新专项页已经明确支持。概要能力应以新专项页与实时界面为准。[旧页](https://mubu.com/help/28)、[新页](https://mubu.com/help/122)
- 快捷键总表中 Shift+Tab 的导图备注写成创建下级，与导图专项页的插入上级冲突。需要实际按键确认，不能凭表直接实现。[总表](https://mubu.com/help/14)、[专项页](https://mubu.com/help/28)
- 「自定义编辑工具栏」公开说明仅手机/平板支持，不应据此给电脑网页设计虚构入口。[工具栏](https://mubu.com/help/123)

## 必须由当前界面补齐的观察

1. 文档页整体层级、工具栏分组、侧栏展开方式、菜单密度、暗色与窄窗口行为。
2. 大纲光标/选择/多选各状态的 Enter、Tab、Shift+Tab、Backspace、Shift+Enter、Esc，以及撤销后的焦点。
3. 拖拽重排的插入线、退级/升级反馈、折叠子树携带、超长内容自动滚动。
4. 导图结构/样式选项全集、布局切换的视口与选区保留、文字自动尺寸、跨分支关系线行为。
5. 主题详情面包屑、空状态、无匹配搜索、失效引用、保存失败与导出错误反馈。
